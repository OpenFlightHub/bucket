# OpenFlightHub Bucket

## Documentation

This is a minio bucket. See documentation here: https://min.io/docs/minio/container/index.html

Set the secrets `MINIO_ROOT_USER` and `MINIO_ROOT_PASSWORD` on github action secrets

## Configure

* log into the minio console
* in the "configuration" set region to "eu-1"
* restart the instance

## Configure locally (for dev)

* log into the minio console
* create a new bucket called 'test'
* in the "configuration" set region to "eu-1"
* restart the instance
